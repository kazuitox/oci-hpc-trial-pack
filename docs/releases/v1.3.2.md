# OCI HPC Trial Pack v1.3.2

## 変更内容

- 新規AutoscalingノードのOCI表示名・DNS・inventory同期をSlurm起動前へ移し、ジョブ開始時のコストタグ更新との競合を抑制しました。
- インスタンスが「変更中」の場合の `409 Conflict` に上限付き再試行を追加しました。
- 構築の未完了段階を記録し、失敗後に名前同期・構築・監視設定の必要な段階から再開するようにしました。
- Resource Manager用のTerraform指定を `~> 1.5.0, < 1.6` に修正しました。Autoscaling側は従来どおり1.5.0以上です。

## 確認範囲・注意点

- ローカル回帰テスト514件中513件成功、1件スキップ（Terraform 1.7以上が必要な既存テスト）。Terraform 1.5.7での構成検証も成功しました。
- Resource Managerへのフォルダアップロード成功を利用者が確認済みです。OCIでのApply・実ジョブによるAutoscaling試験は今回のリリース作業では実施していません。
- ルート構成はTerraform 1.5.xが対象です。IAM・providerバージョンは変更していません。リリース公開だけでは既存コントローラのファイルは更新されません。
