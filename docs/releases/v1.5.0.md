# OCI HPC Trial Pack v1.5.0

## 追加・改善内容

- **Autoscaling の残存インスタンス監視**：OCI・Slurm・inventory を照合し、作成・削除の停滞や未登録・障害ノード、アイドル状態で残る計算インスタンスを管理者へ通知します。自動削除は行いません。
- **OOD Files のZIPなし保存**：複数ファイルやフォルダを階層ごと保存し、同じダイアログで合計サイズ・保存名・転送進捗を確認できます。容量確認のタイムアウトは既定300秒です。
- **ファイル転送上限50 GB**：OOD Files のアップロードと、単一ファイル・フォルダのダウンロード上限を50 GB（50,000,000,000バイト）に変更しました。
- **OpenComposer のキャンセル状態表示**：キャンセルされたジョブを `Canceled` として保存・表示し、絞り込みと並べ替えに対応しました。過去履歴の補正は含みません。

## 既存環境を更新する場合

Resource Manager の構成ZIPを更新し、Plan で変更対象を確認してから Apply してください。管理者通知が有効なスタックには残存監視と読み取り権限が追加されます。通知の既定値は無効のままです。

OOD の変更は、更新した role 全体をコントローラへ配布して再適用してください。転送上限の変更時には利用者のWebプロセスが再起動されるため、転送を終えた保守時間に実施します。

## 検証

各ブランチでの動作確認と、統合版の Resource Manager デプロイ成功が利用者から報告されています。マージ後の個別機能の再テストは省略しました。OS・構成・個別シナリオの内訳は記録していません。

ローカル回帰テストは641件、失敗0件・スキップ4件でした。スキップに含まれた Terraform バージョン制約は別途確認済みです。Terraform のルート構成・動的ノード用構成の検証と、変更した Ansible タスクの構文確認も成功しています。

添付の `oci-hpc-trial-pack-v1.5.0.zip` は、Terraform の構成ファイルをZIP直下に配置し、`.git` を含みません。
